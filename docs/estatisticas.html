Critérios de contagem

Uma unidade é um registro do arquivo público leitura/dados.json; não é necessariamente uma frase. Tokens são sequências de letras Unicode, admitindo apóstrofo e hífen internos. Tipos são formas distintas, sem distinção de maiúsculas/minúsculas. A pontuação não é contabilizada. O léxico conta entradas, não necessariamente lemas únicos. Traduções ausentes são registros cujo campo português está vazio.

Os números mudam automaticamente quando o arquivo público é atualizado. Estes indicadores não medem cobertura de anotação morfossintática nem qualidade de alinhamento.
