# Editor de textos paralelos

Abra `editor/index.html` em um navegador (ou publique a pasta via hospedagem estática, quando autorizado). Importe um par `NN_xav.txt` / `NN_por.txt`, revise lado a lado, busque/substitua e exporte os dois TXT corrigidos.

O salvamento é no armazenamento local do navegador, **não** no GitHub. Para incorporar correções, envie os arquivos exportados ao repositório. Não há login nem colaboração simultânea nesta primeira versão. O editor não precisa de backend.

A interface segue a proposta visual do corpus Bororo, mas ainda não reproduz todas as ferramentas avançadas daquele projeto.
